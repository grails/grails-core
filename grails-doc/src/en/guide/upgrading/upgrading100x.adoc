=== Upgrade Instructions for Grails 9 to Grails 10

This guide outlines the changes introduced in Grails 10 and the steps required to upgrade your application.

==== 1. GPars Modules Removed

Grails 9 deprecated `grails-async-gpars` and `grails-events-gpars` because Groovy 6 provides the same patterns in `groovy.concurrent`. Grails 10 removes both modules.

Replace a GPars promise factory with `grails-async-groovy-concurrent` (`org.grails.async.factory.groovy.AwaitablePromiseFactory`). Replace a GPars event bus with `grails-events-groovy-concurrent` (`org.grails.events.groovy.ActorEventBus`). Only one service-loaded `PromiseFactory` is used, and the event bus builder refuses to start when more than one `EventBus` implementation is on the classpath.

The cache plugin no longer depends on GPars. An application that calls GPars directly, for example `GParsPool.withPool`, must declare `org.codehaus.gpars:gpars` itself. Prefer the Groovy equivalents: parallel collection methods are available on every `Collection`, and `groovy.concurrent.ParallelScope.withPool` runs them on a pool of a chosen size.
